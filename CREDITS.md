# Crédits

## Jeux d'origine

Tous les jeux, graphismes, sons, musiques, textes et sources proviennent de l'archive
[motion-twin/WebGamesArchives](https://github.com/motion-twin/WebGamesArchives) publiée par **Motion Twin**,
sous licence [Creative Commons Attribution - Pas d'Utilisation Commerciale - Partage dans les Mêmes Conditions 4.0 International](https://creativecommons.org/licenses/by-nc-sa/4.0/deed.fr).

Jeux de Motion Twin (2001-2015) : Frutiparc, KadoKado, Dinoparc, Socratomancie, Dinocard, Pioupiouz, Miniville,
Alphabounce, CaféJeux, DinoRPG, Hordes, SkyWar, Muxxu (Intrusion, Kingdom, Fever, Kube, La Brute, Snake, CroqueMotel, Odyssey),
Naturalchimie 2, La Bourinette, Mush, Galaxy55, Teacher Story, Arkadeo, Uppercup Football, Rockfaller Journey, Monster Hotel.

Hammerfest n'est volontairement pas inclus.

## Ce dépôt

KotionTwin est un projet de fan **non commercial**, sans lien avec Motion Twin. Les adaptations (loaders, API simulées,
recompilations, portages HTML5, interface du site) sont redistribuées sous la même licence CC BY-NC-SA 4.0.

## Sons ajoutés

Alphabounce était muet à l'origine. Les bruitages (rebond de la balle, brique cassée, bonus) et les
musiques d'ambiance ajoutés par KotionTwin (`games/alphabounce/sons/`) sont des créations faites avec Suno ;
ils ne viennent pas de l'archive Motion Twin.
